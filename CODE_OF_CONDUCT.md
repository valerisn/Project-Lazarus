# Code of Conduct

Project Lazarus is a small fan project fixing a game a lot of people were disappointed by. Keep the frustration aimed at the bugs, not at each other.

## Expected

* Be respectful to everyone, whatever their experience level. Someone asking "how do I find my game folder" is as welcome as someone sending a hook for a softlock.
* Criticize code, ideas and decisions, not people.
* Assume good faith. Text loses tone, so ask before deciding someone meant harm.
* Back technical claims with evidence (logs, repro steps, reasoning), and accept being corrected the same way.
* Respect people's time: search existing issues, fill in the templates, attach your log.

## Not acceptable

* Harassment, insults, slurs, or personal or political attacks.
* Sexualized content, or unwelcome attention of any kind.
* Publishing someone's private information without their permission.
* Harassing the game's developers or publisher on behalf of this project. Criticizing the game is fine; going after individuals isn't.
* Posting pirated game files, cracks, or links to them. Lazarus works with legitimate copies and never touches DRM. (See also [CONTRIBUTING.md](CONTRIBUTING.md).)
* Sustained disruption of discussions, or deliberately derailing issues.

## Scope

This applies in the repository (issues, pull requests, discussions, commits, reviews) and anywhere someone is representing the project.

## Enforcement

Report problems to the maintainer. For anything sensitive, use a private channel: open a [private security advisory](https://github.com/valerisn/Project-Lazarus/security/advisories/new) marked "conduct report", or contact the maintainer through their GitHub profile. Reports are kept confidential.

Depending on severity, the maintainer may edit or remove content, warn, temporarily restrict, or permanently ban someone from the project. Decisions take the whole context into account, and the person reported gets a chance to respond unless that would put someone at risk.

This code takes inspiration from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
